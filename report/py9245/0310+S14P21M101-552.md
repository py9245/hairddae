# 2026-03-10 S14P21M101-552

## 이슈
- [W2][BE] DB 연결 + Flyway 초기 마이그레이션
- Jira: `S14P21M101-552`

## 작업 요약
- Spring Boot 애플리케이션에 Flyway 의존성을 추가했다.
- 기본 설정에 Flyway 마이그레이션 경로를 연결했다.
- PostgreSQL 기준 초기 스키마 `V1__initial_schema.sql`을 추가했다.
- 초기 스키마에는 `users`, `hairs`, `hair_likes`, `histories`, `jobs`, `ads` 테이블과 기본 인덱스를 포함했다.

## 변경 파일
- `BE/build.gradle`
- `BE/src/main/resources/application.yml`
- `BE/src/main/resources/db/migration/V1__initial_schema.sql`

## 검증
- `docker compose -f BE/docker-compose.local.yml down -v`
- `docker compose -f BE/docker-compose.local.yml up -d --build postgres redis app nginx`
- 앱 로그에서 Flyway `v1 - initial schema` 적용 확인
- PostgreSQL에서 `flyway_schema_history` 및 생성 테이블 확인
- `nginx/local.conf` 기준 HTTPS `/api/health` 응답 확인

## 비고
- 로컬 검증은 `BE/docker-compose.local.yml`로 수행했지만, 실제 배포 반영은 `BE/docker-compose.yml`에서 구동되는 동일한 앱 이미지에 포함된다.
- `main`, `BE` 브랜치에는 직접 커밋하지 않고 이슈 브랜치와 레포트 브랜치를 분리해 작업했다.
