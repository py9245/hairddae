# 2026-03-10 S14P21M101-553

## 이슈
- [W2][BE] 엔티티 설계(User/Hair/Like/History/Job/Ad)
- Jira: `S14P21M101-553`

## 작업 요약
- Flyway 초기 스키마에 맞춘 JPA 엔티티 6종을 추가했다.
- 공통 생성/수정 시간을 위한 `BaseTimeEntity`를 도입했다.
- `Gender`, `JobType`, `JobStatus` enum을 분리했다.
- 각 엔티티에 대응하는 Spring Data JPA Repository 6종을 추가했다.
- 기존 인메모리 기반 서비스는 유지하고, 이후 DB 연동 확장을 위한 persistence 계층만 우선 구성했다.
