## 이슈
- [W2][BE] Spring Security 기본 설정 + CORS
- Jira: `S14P21M101-555`

## 작업 요약
- 기존 JWT 기반 Spring Security 설정에 CORS 설정을 연결했다.
- `app.security.cors.allowed-origins` 설정 프로퍼티를 추가해 로컬/배포 origin을 환경변수로 제어할 수 있게 했다.
- 전체 경로에 대해 `GET, POST, PUT, PATCH, DELETE, OPTIONS` 메서드를 허용하고, 인증 관련 헤더 노출 설정을 추가했다.
- Preflight 요청이 인증 전에 차단되지 않도록 `OPTIONS /**`를 허용했다.

## 변경 파일
- `BE/src/main/java/com/example/beapp/config/AppCorsProperties.java`
- `BE/src/main/java/com/example/beapp/config/SecurityConfig.java`
- `BE/src/main/resources/application.yml`

## 검증
- `docker compose -f BE/docker-compose.local.yml up -d --build postgres redis app nginx`
- 앱 로그에서 Spring Boot 기동, Flyway 검증, JPA 초기화 완료 확인
- `app` 컨테이너에서 `curl -k -i -X OPTIONS https://nginx/api/mypage/user ...`로 preflight 요청 수행
- 응답 헤더에서 `Access-Control-Allow-Origin`, `Access-Control-Allow-Methods`, `Access-Control-Allow-Headers` 확인
- `docker compose -f BE/docker-compose.local.yml down`

## 비고
- 호스트 셸의 `localhost:443` 접근은 이 세션 샌드박스에서 제한돼 있어, 컨테이너 내부에서 HTTPS preflight를 검증했다.
- 배포 반영은 별도 compose 수정 없이 `BE` 앱 이미지 변경만으로 동일하게 적용된다.
