## 작업 요약
- `/api/accounts/signin` 회원가입 API에 `passwordConfirm` 필드를 추가했다.
- 서버에서 `password`와 `passwordConfirm` 일치 여부를 직접 검증하도록 보강했다.
- 아이디 중복은 별도 중복체크 API 없이 같은 회원가입 API 응답의 에러 메시지로만 반환하도록 정리했다.
- 중복 아이디일 때는 `409`, 비밀번호 확인 불일치일 때는 `400`으로 응답하게 했다.
- 회원가입 관련 통합 테스트에 비밀번호 확인 불일치와 중복 아이디 케이스를 추가했다.

- `docker compose -f BE/docker-compose.local.yml up -d --build postgres redis app nginx`

- `passwordConfirm` 불일치 시 `400 Bad Request`와 `비밀번호 확인이 일치하지 않습니다.` 메시지 확인
- `docker compose -f BE/docker-compose.local.yml down`
