# 2026-03-10 S14P21M101-560

## 이슈
- [W2][BE] 토큰 재발급 API 구현
- Jira: `S14P21M101-560`

## 작업 요약
- `/api/accounts/refreshToken` 엔드포인트를 구현했다.
- 요청으로 받은 refresh token이 JWT 타입상 유효한지 확인하고, 저장된 refresh token과 일치하는지도 검증한다.
- 기본 동작은 `rotate=true`이며, 재발급 시 새 access token과 새 refresh token을 함께 발급한다.
- 회전된 이전 refresh token은 blocklist 처리해 재사용을 차단한다.
- `rotate=false`일 때는 저장된 현재 refresh token을 유지한 채 access token만 재발급한다.

## 검증 근거
- `ApiSecurityIntegrationTest.refreshRotationInvalidatesPreviousRefreshToken`에서 회전 후 이전 refresh token 재사용 시 `401`을 검증한다.
- 2026-03-10 로컬 도커 검증에서 refresh token 회전 성공, 이전 refresh token 재사용 `401`, 최신 refresh token 유지 재호출 성공을 재확인했다.

## 비고
- 2026-03-10 기준 토큰 재발급 API 구현은 `BE` 브랜치에 포함되어 있어 이번 이슈는 레포트만 추가했다.
- refresh token 재발급은 저장소 검증과 blocklist 차단까지 포함된 상태다.
