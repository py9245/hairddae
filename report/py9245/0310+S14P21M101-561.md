## 이슈

## 작업 요약
- `/api/accounts/logout` 엔드포인트를 구현했다.
- 요청으로 받은 access token을 검증한 뒤 blocklist 처리해 즉시 재사용을 막는다.
- refresh token이 함께 전달되면 저장된 refresh token과 일치하는지 검증하고 blocklist 처리한다.
- 로그아웃 시 사용자에게 저장된 refresh token을 삭제해 이후 재발급 시도를 차단한다.
- 결과는 공통 응답 형태로 `로그아웃 완료` 메시지를 반환한다.

- `ApiSecurityIntegrationTest.logoutBlocksIssuedAccessToken`에서 로그아웃 후 기존 access token 재사용 시 `401`을 검증한다.
- 2026-03-10 로컬 도커 검증에서 로그아웃 후 최신 refresh token 재사용도 `401`로 차단되는 것을 재확인했다.
